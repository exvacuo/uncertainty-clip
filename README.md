# uncertainty-clip

Train both CLIP encoders from scratch on COCO 2017, then study uncertainty
estimation. The default model is **ViT-B/32**, using OpenCLIP 3.2.0.
ViT-B/16 and RN50 are also supported.

The CPU pipeline check passed on real COCO images and saved checkpoints.
Model, retrieval, and checkpoint/resume tests pass. GPU training, model quality,
and uncertainty experiments remain to be evaluated.

## Setup

Python 3.13 is selected in `.python-version`. Install the pinned environment:

```bash
uv sync --locked
uv run utilities/download_coco.py
uv run python -m uncertainty_clip prepare
```

Dataset files and generated run artifacts are excluded from Git. The split
manifest is generated by `prepare`; transfer it with the dataset or regenerate
it with the same defaults on the target machine.

## Run

Run from the repository root:

```bash
# Quick CPU pipeline check; use a fresh output directory for each run.
uv run python -m uncertainty_clip train --config configs/vit-b32-smoke.toml

# On the intended NVIDIA GPU: compare training speed and memory for all three models.
uv run python -m uncertainty_clip benchmark --output runs/compute-estimate.json

# GPU pilot: 8,192 training images, three epochs, ViT-B/32.
uv run python -m uncertainty_clip train --config configs/vit-b32-pilot.toml
```
